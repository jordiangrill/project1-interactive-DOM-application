# project1-interactive-DOM-application

Racing game made with HTML, CSS, Javascript and DOM manipulation. 

It includes user input, UI feedback and state tracking. Also a bit of KISS and DRY. 

The MVP was to achieve our car racing and being able to collide with our main rival. 

Extras:

Debries on track (oil and batteries)
The random spawn of the three objects
The speed mecanics and interactions between the player, the track and the objects
Insert audio track

AI helped with creative design ideas. For the code it was used as a teacher guiding a novice programmer with hints. At least up until the MVP. If I was stuck I did ask for a little more help but never with direct code.
After reaching the MVP, I needed a bit more help to think and implement the more complex dynamics to make the game more interesting with its random spawns, velocity interaction, etc. 

Things learned:

HTML:

How to insert an audio
How to apply a screen reader to the game with 'aria-live': off / polite / assertive

CSS:

Z-index and a few more design parameters to improve the art quality. Also the pointer-events, although irrelevant for once the game started.

Javascript:

With the velocity and random spawn I needed more help from the AI because it was almost imposible to do it in just two days and I wanted to have a funnier game! But I think I let it overcomplicate too much codewise.
